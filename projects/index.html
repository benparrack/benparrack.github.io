Things I've built

A running list of things I've made. More get added as I finish them.

Hydroponics Control System

Electronics lead on an interdisciplinary team project. Built an Arduino-based sensor and pump control system to regulate nutrient delivery, with pH and TDS probes feeding human-readable readings. Presented to 50+ people.

Arduino Sensors Embedded

VT Gym Occupancy Graph Program

A Python web scraper that pulls gym occupancy data every 5 minutes, caches it with pickle, and visualizes trends with matplotlib so students can time their gym visits better.

Python Web Scraping matplotlib

LLM-Assisted Classroom Behavior Evaluation

Research comparing LLM analysis of structured learning-environment video against real scenarios, using the gaps found to refine prompts for classifying behaviors and postures.

LLMs Prompt Engineering Research
